# 🎮 Telegram-бот «Правда или Действие»

Простой интерактивный Telegram-бот для игры в **«Правда или Действие»**, написанный на Python с использованием библиотеки `python-telegram-bot` версии 20+. Бот предлагает пользователям выбирать между каверзными вопросами и весёлыми заданиями с помощью удобных инлайн-кнопок.

## ✨ Особенности
* 🎲 Случайный выбор вопросов («Правда») и заданий («Действие»).
* 🔘 Интуитивное управление через встроенные (Inline) кнопки.
* 📦 Структурированное хранение игровых данных в формате JSON.
* 🪵 Логирование основных событий для контроля работы бота.

## 🛠 Требования к окружению
Для запуска бота вам понадобятся:
* **Python 3.8** или выше
* Зависимости, указанные в файле `requirements.txt` (основная библиотека — `python-telegram-bot`)

## 🚀 Быстрый запуск

### 1. Подготовка файлов
Убедитесь, что в одной папке со скриптом бота находится файл конфигурации данных `data.json` со следующей структурой:

```json
{
  "truth": {
    "default": [
      "Какую самую глупую вещь вы делали ради спора?",
      "Чего вы боитесь больше всего на свете?"
    ]
  },
  "dare": {
    "default": [
      "Спойте припев вашей любимой песни прямо сейчас.",
      "Присядьте 10 раз."
    ]
  }
}
```

### 2. Установка зависимостей
Установите необходимую библиотеку для работы с Telegram API:
```bash
pip install python-telegram-bot
```

### 3. Настройка токена
Откройте скрипт бота и замените значение переменной `BOT_TOKEN` на токен, полученный от [@BotFather](https://t.me/BotFather):
```python
BOT_TOKEN = "ВАШ_РЕАЛЬНЫЙ_ТОКЕН"
```

### 4. Запуск скрипта
Запустите бота через терминал или командную строку:
```bash
python bot.py
```

## 📝 Использование
1. Перейдите в чат с ботом в Telegram и введите команду `/start`.
2. Нажмите кнопку **«🎤 Правда»** для получения случайного вопроса или **«🏃 Действие»** для получения задания.
3. Раздел **«🔒 Доп. Категории»** зарезервирован для будущих обновлений игры.
